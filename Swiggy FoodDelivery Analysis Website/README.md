# Swiggy Food Intelligence Project



## Key Features
- **Exploratory Data Analysis (EDA):**
  - Distribution of delivery times, prices, and ratings
  - Identification of top cuisines and cities
- **Hypothesis Testing:**
  - One-sample t-tests for delivery time and ratings benchmarks
  - ANOVA for cuisine-based delivery time differences
  - Chi-square tests for city–cuisine associations
- **Machine Learning Models:**
  - Regression models to predict delivery time  
    - **XGBoost** achieved the best performance (R² ≈ 0.67)
  - Classification models for:
    - **Fast vs. Slow delivery**
    - **Premium vs. Budget segments**
    - Logistic Regression delivered the highest accuracy (~89%)



## Tech Stack
- **Languages & Libraries:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost
- **Techniques:** EDA, Hypothesis Testing, Regression, Classification, Cross-Validation
- **Model Export:** Joblib for saving trained models

## Models made
- `Swiggy_FoodDeliveryTimePrediction_Model.pkl` → Delivery time prediction model
- `Price_Classification.pkl` → Price segment classification model
